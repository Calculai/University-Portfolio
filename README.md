# University Portfolio

This repository brings together selected programming and computer science coursework completed at university. It is an archive of assignments and experiments, organized to make the work easier to browse.

The projects reflect the requirements and conventions of their original courses. They are as when they were written so they don't reflect my current code style and some were made with no intention of ever being used again so not as much care has been taken to make it readable and maintainable.

## Understanding coursework contributions

Some assignments started from course-provided repositories or files. Where available, a `contributions.patch` file records changes made for the assignment; check it alongside the assignment README to see the implementation in context.
