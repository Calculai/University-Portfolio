# University portfolio

This is not a formal project; more so, it is me scraping together everything I have done at university.

It is to make it available to look through. I have tried making it a bit easier, but it was never meant
to be shared in this format, so it isn't designed with it in mind. It will contain scripts that have no
comments and scripts that have overexplained comments to show understanding to the instructor, depending on the assignment I was working on.

I could go through and re-document everything, but that would be time-consuming, or, if done with AI, wouldn't be demonstrative of my work, so I have decided to leave it in its rather crude state.

Feel free to look around. I have also made a longer list of the skills demonstrated across the assignments.

In order to make it a little easier to parse what I did, I made Copilot generate a contributions.patch that shows what I have removed from the original structure and then added to it, and it is in each of the different relevant folders. Other times, like in Numerical Linear Algebra with comp.py, all the code is by me, so no contributions.patch is needed.

Lastly, I had Copilot whip up an HTML page for each to help make it easier to navigate.
