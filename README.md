# University portfolio

This is not a formal project moreso it is me scraping together everything I have done in university.

It is to make it available to look through I have tried making it a bit easier but it was never meant
to be shared in this format so it isn't designed with it in mind. It will contain scripts that have no
comments and scripts that have overexplained comments to show understanding to the instructor dependent on the assignment I was working on.

I could go through and redocument everything but that would be time consuming or if done with AI wouldn't be demonstrative of my work so I have decided to leave it in its rather crude state.

Feel free to look around. I have also made a longer list of the skills demonstrated across the assignments.

In order to make it a little easier to parse what I did I made Copilot generate a contribution.patch that shows what I have removed from the original sturcture and then added to it and it is in each the different relevant folders.  Other times like in numerical algebra with comp.py all the code is by me so no contribution.patch needed.

Lastly I had Copilot whip up a html for each to help making it easier to navigate.
