# Skills demonstrated
## Programming

- **Writing programs in C:** implementing exercises involving functions, arrays, strings, pointers, structs, linked lists, stacks, queues, and trees. See [IPFCE 3](projects/ipfce/assignment-03/README.md), [IPFCE 6](projects/ipfce/assignment-06/README.md), and [IPFCE 9](projects/ipfce/assignment-09/README.md).
- **Writing programs in C++:** using classes, templates, standard library containers, and modern C++ features in larger exercises. See [SOFACE 2](projects/soface/assignment-02/README.md), [SOFACE 3](projects/soface/assignment-03/README.md), and [SOFACE 5](projects/soface/assignment-05/README.md).
- **Writing scientific Python:** using Python for numerical experiments, visualisation, and working with matrix-based problems. See the [Numerical Linear Algebra work](NUMERICAL-LINEAR-ALGEBRA.html).
- **Turning written requirements into implementations:** reading an exercise specification, matching required function signatures, and implementing the requested behaviour. See [IPFCE 11](projects/ipfce/assignment-11/README.md) and [SOFACE 3](projects/soface/assignment-03/README.md).
- **Working within an existing codebase:** adding implementations to provided headers, source files, test suites, and project structures instead of starting from an empty project. See [IPFCE 4](projects/ipfce/assignment-04/README.md) and [SOFACE 7](projects/soface/assignment-07/README.md).

## Problem solving

- **Decomposing problems into smaller functions:** separating a larger task into helpers with clear responsibilities. See [IPFCE 5](projects/ipfce/assignment-05/README.md) and [SOFACE 4](projects/soface/assignment-04/README.md).
- **Designing and applying algorithms:** reasoning about the steps needed to solve a problem and implementing them in code. See [IPFCE 7](projects/ipfce/assignment-07/README.md), [IPFCE 8](projects/ipfce/assignment-08/README.md), and [IPFCE 10](projects/ipfce/assignment-10/README.md).
- **Choosing and implementing data structures:** working with arrays, linked structures, stacks, queues, and binary trees according to the problem being solved. See [IPFCE 6](projects/ipfce/assignment-06/README.md), [IPFCE 9](projects/ipfce/assignment-09/README.md), and [IPFCE 10](projects/ipfce/assignment-10/README.md).
- **Reasoning about edge cases:** considering invalid input, boundary conditions, empty structures, and different control-flow paths. See [IPFCE 4](projects/ipfce/assignment-04/README.md) and [SOFACE 10](projects/soface/assignment-10/README.md).
- **Applying mathematical reasoning to code:** implementing numerical methods and connecting mathematical definitions to executable algorithms. See the [Numerical Linear Algebra work](NUMERICAL-LINEAR-ALGEBRA.html) and [SOFACE 7](projects/soface/assignment-07/README.md).

## Software design

- **Encapsulation and abstraction:** organising data and operations behind interfaces rather than exposing every implementation detail. See [SOFACE 2](projects/soface/assignment-02/README.md) and [SOFACE 3](projects/soface/assignment-03/README.md).
- **Polymorphism and generic programming:** using function pointers, inheritance or templates to support interchangeable implementations. See [SOFACE 2](projects/soface/assignment-02/README.md), [SOFACE 5](projects/soface/assignment-05/README.md), and [SOFACE 12](projects/soface/assignment-12/README.md).
- **Applying design patterns:** recognising and implementing patterns such as strategy, visitor, observer, template method, and pipes and filters. See [SOFACE 4](projects/soface/assignment-04/README.md), [SOFACE 5](projects/soface/assignment-05/README.md), [SOFACE 9](projects/soface/assignment-09/README.md), and [SOFACE 12](projects/soface/assignment-12/README.md).
- **Separating responsibilities:** structuring programs into components that can be changed or tested independently. See [SOFACE 3](projects/soface/assignment-03/README.md), [SOFACE 6](projects/soface/assignment-06/README.md), and [SOFACE 8](projects/soface/assignment-08/README.md).
- **Working with interfaces and dependencies:** designing code around replaceable components, logging, and dependency injection. See [SOFACE 3](projects/soface/assignment-03/README.md).

## Testing and quality

- **Writing and running tests:** checking implementations against expected results and using test failures to find incorrect behaviour. See [IPFCE 4](projects/ipfce/assignment-04/README.md), [IPFCE 11](projects/ipfce/assignment-11/README.md), and [SOFACE 10](projects/soface/assignment-10/README.md).
- **Using test-driven feedback while implementing:** repeatedly compiling and testing partial implementations until the required cases pass. See [SOFACE 7](projects/soface/assignment-07/README.md) and [IPFCE 11](projects/ipfce/assignment-11/README.md).
- **Analysing control flow and complexity:** drawing control-flow graphs and calculating cyclomatic complexity to identify independent execution paths. See [SOFACE 10](projects/soface/assignment-10/README.md).
- **Thinking about software specifications:** matching exact interfaces, signatures, input assumptions, and expected outputs. See [IPFCE 11](projects/ipfce/assignment-11/README.md) and [SOFACE 11](projects/soface/assignment-11/README.md).
- **Using automated checks:** working with scripts and automated workflows that compile and test multiple exercises. See [IPFCE 11](projects/ipfce/assignment-11/README.md).

## Systems and applied programming

- **Managing memory and understanding allocation:** working with allocation strategies, heap behaviour, and the relationship between memory use and performance. See the [memory allocation experiment](projects/computer-architecture/memory-allocation/README.md).
- **Working with pointers and indirect data:** using addresses, references, dynamically allocated structures, and pointer-based data structures in C and C++. See [IPFCE 6](projects/ipfce/assignment-06/README.md) and [IPFCE 9](projects/ipfce/assignment-09/README.md).
- **Using concurrency:** dividing work between threads and reasoning about shared data and whether synchronisation is required. See [SOFACE 7](projects/soface/assignment-07/README.md).
- **Working with networking libraries:** building programs that communicate over network connections and handling the structure of asynchronous or client/server code. See [SOFACE 6](projects/soface/assignment-06/README.md).
- **Working with messaging and distributed components:** using message-based communication to connect separate parts of a program. See [SOFACE 8](projects/soface/assignment-08/README.md).
- **Working with external libraries and build systems:** integrating libraries such as Boost.Asio and ZeroMQ into coursework projects and building programs through the provided project setup. See [SOFACE 6](projects/soface/assignment-06/README.md) and [SOFACE 8](projects/soface/assignment-08/README.md).
- **Considering data layout and performance:** relating matrix operations to row-major or column-major storage, partitioning work, and considering complexity. See [SOFACE 7](projects/soface/assignment-07/README.md).

- **Explaining implementation decisions:** documenting reasoning where an assignment asks for calculations, comparisons, or design justification. See [SOFACE 10](projects/soface/assignment-10/README.md) and the [Numerical Linear Algebra work](NUMERICAL-LINEAR-ALGEBRA.html).
- **Working across different scales of project:** moving between small exercises, reusable components, complete programs, experiments, and numerical notebooks or scripts. See the [portfolio README](README.md).
