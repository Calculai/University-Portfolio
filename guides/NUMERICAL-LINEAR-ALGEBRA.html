HW 1 · Vector chains and rotations

Assignment context A planar arm is represented by connected vectors, and selected segments are rotated.

Implementation Builds the segment vectors from points, sums them to recover the endpoint, and applies rotation matrices to compare rotating a terminal segment with rotating a downstream chain.

Presentation Uses labeled vector plots to make the geometry and changed endpoint visible.

HW 3 · Smoothing a noisy signal

Assignment context Starts from a sampled trigonometric signal, adds normally distributed noise, and compares two banded smoothing matrices.

Implementation Constructs the diagonal matrices, applies them to the noisy samples, and compares errors over repeated noise trials.

Presentation Optional plots show the signal before and after smoothing; error summaries compare the methods quantitatively.

HW 4 · Polynomial interpolation

Assignment context Uses measured points to study polynomial fits and piecewise cubic interpolation.

Implementation Evaluates polynomials, searches for the smallest exact degree, solves an augmented system by row operations, and adds a derivative constraint to select a unique piecewise solution.

Presentation Separate plots compare the data with quadratic, global, and piecewise fits.

HW 5 · Projection and orthogonality

Assignment context Tests whether vectors are orthogonal and studies projection onto their span.

Implementation Forms the Gram matrix, computes projection coefficients, finds the residual, checks its orthogonality, and normalizes the resulting vectors.

Presentation Part switches control which matrix and orthogonality checks are printed; this submission records the numeric results in the console rather than saving a plot.

HW 7 · Singular value decomposition

Assignment context Rotates and samples a figure-eight curve, adds noise, and examines the centered data.

Implementation Centers the samples, computes the SVD, checks orthogonality of the left singular vectors, and rotates the data into principal coordinates for an alignment-error measure.

Results Existing images show the generated curve, noisy samples, and before/after alignment.

HW 8 · Best approximation in a function space

Assignment context Approximates a target function with a span of basis functions over an interval.

Implementation Approximates inner products numerically with the trapezoidal rule, forms the Gram system, solves for projection coefficients, and measures approximation error.

Results The saved figure places the target function beside its computed approximation.

HW 10 · Least-squares illumination design

Assignment context Models illumination across a parking lot from a fixed set of lamps and targets a specified light level.

Implementation Builds the coefficient matrix with NumPy broadcasting, implements modified Gram–Schmidt QR and back-substitution, then solves and compares the least-squares problem using QR and SVD.

Results Heatmaps show predicted illumination and deviations for both numerical methods.

HW 12 · Coupled mixing tanks

Assignment context Models salt moving between two constant-volume tanks with specified flows and initial concentrations.

Implementation Derives the flow balance and matrix ODE, computes eigenpairs and initial coefficients, evaluates the trajectory, and obtains the long-term concentration ratio from the dominant eigenvector.

Results Existing figures show the system construction and the simulated tank trajectories.
